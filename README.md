# I2P Final Project Group 23

# 數到100

《數到100》是一款使用 **Python + pygame-ce** 製作的 2D 劇情解謎遊戲。

玩家將跟隨主角黎琛，在異常的空間與不同時間點之間探索，透過調查環境、蒐集線索、解開機關與做出選擇，逐步了解在自己身邊發生的真相。

---

## 遊戲類型

- 2D 劇情探索
- 解謎
- 場景互動
- 道具蒐集
- 多空間／時間探索

---

# 如何開始遊戲

## 1. 下載專案

在 GitHub 專案頁面點選：

code → Download ZIP

下載完成後，將 ZIP 檔解壓縮到任意資料夾。

---

## 2. 安裝 Python

遊戲需要 Python 才能執行。

建議使用Python 3.14 以上的版本

安裝完成後，可以在終端機輸入：

```bash
python --version
```

確認 Python 是否已正確安裝。

---

## 3. 安裝 pygame-ce

開啟 PowerShell、Command Prompt 或其他終端機，輸入：

```bash
pip install pygame-ce
```

安裝完成後，可以使用：

```bash
pip show pygame-ce
```

確認 pygame-ce 是否已成功安裝。

---

## 4. 啟動遊戲

進入遊戲專案資料夾後執行：

```bash
python game_home.py
```

也可以使用 VS Code 開啟專案後，執行：

```text
game_home.py
```

遊戲視窗就會開啟。

---

# 基本操作

## 探索

| 操作 | 按鍵 |
|---|---|
| 向上移動 | `W` |
| 向下移動 | `S` |
| 向左移動 | `A` |
| 向右移動 | `D` |
| 滑鼠移動 | 點擊可行走的位置 |
| 與物件互動 | `E` |
| 開啟設定 | `Esc` |

玩家也可以直接使用滑鼠點擊場景中的位置，角色會嘗試自動走到指定位置。

---

## 對話

| 操作 | 按鍵 |
|---|---|
| 推進對話 | `Enter` |
| 推進對話 | `Space` |

部分劇情選擇可以使用方向鍵進行選擇，再按下 `Enter` 確認。

在部分選擇畫面中，也可以直接使用：

```text
A
B
C
```

選擇對應選項。

---

## 道具欄

遊戲探索過程中取得的部分道具會出現在道具欄。

可使用 ← / → 切換目前選取的道具。
也可以使用 12345 數字鍵快速選取對應位置的道具。

滑鼠滾輪也可以切換道具。

---

# 解謎操作

遊戲中包含多種類型的 Puzzle，因此不同謎題的操作方式可能不同。

## 密碼鎖

部分密碼鎖使用滑鼠操作。

將滑鼠移到數字鎖的：

- 上方區域：向上轉動數字
- 下方區域：向下轉動數字

調整完成後按下：

```text
確認
```

提交答案。

如果想暫時離開，可以使用：

```text
返回
```

或：

```text
Esc
```

尚未成功解開前，重新開啟同一個密碼鎖時，先前調整的數字會暫時保留。

---

## 拖放型謎題

部分謎題需要：

```text
滑鼠左鍵按住
→ 拖曳物件
→ 放到指定位置
```

如果物件放錯位置，可以重新拖曳。

---

## 其他 Puzzle

遊戲中還有其他不同形式的解謎機制。

建議仔細觀察：

- 場景中的物件
- 角色對話
- 已取得的道具
- 日記與文字內容
- 不同時間點之間的差異

許多線索會在不同場景之間互相呼應。

---

# 遊戲目標

玩家需要探索不同空間，尋找散落在環境中的線索，並逐步解開各個機關。

遊戲不會直接告訴玩家所有答案。

當遇到無法解開的謎題時，可以嘗試：

1. 探索其他物件。
2. 查看目前取得的道具。
3. 回想先前看到的文字或數字。
4. 前往其他已解鎖的空間。
5. 比較不同時間點的場景差異。

---

# 存檔與讀檔

遊戲支援 **3 個獨立存檔欄位**。

開始遊戲時，可以選擇：

```text
新遊戲
```

或：

```text
讀取遊戲
```

並選擇要使用的存檔欄位。

遊戲中也可以透過設定選單進行存檔。

如果存檔欄位已經存在資料，遊戲在覆蓋前會再次要求確認。

---

## 刪除存檔

在讀取存檔畫面中，可以使用：

```text
R
```

進入刪除存檔流程。

遊戲會要求玩家進行兩次確認。

第二次會顯示：

```text
你真的確定要刪除嗎？
請注意此操作無法復原。
```

刪除後無法恢復該存檔。

---

# 遊戲視窗

遊戲預設使用：

```text
800 × 600
```

的 4:3 視窗。

玩家可以拖曳調整視窗大小。

遊戲會自動維持：

```text
4:3
```

的畫面比例，以避免場景、UI 與互動位置變形。

---

# 遊戲結束

部分謎題具有失敗次數限制。

如果達到錯誤次數上限，有可能進入：

```text
GAME OVER
```

此時可以選擇：

- 重新開始
- 回到主選單
- 開啟設定

因此在提交答案前，建議先確認目前找到的線索。

# 常見問題

## 執行 `game_home.py` 後沒有反應

先確認 Python：

```bash
python --version
```

接著確認 pygame-ce：

```bash
pip show pygame-ce
```

如果尚未安裝，可以執行：

```bash
pip install pygame-ce
```

然後重新執行：

```bash
python game_home.py
```

---

## 出現 `No module named pygame`

請執行：

```bash
pip install pygame-ce
```

如果電腦上同時安裝多個 Python 版本，也可以嘗試：

```bash
python -m pip install pygame-ce
```

---

## 遊戲畫面比例改變

遊戲目前固定使用 4:3 畫面比例。

拖曳視窗時，遊戲會自動將尺寸修正為最接近的 4:3 比例。

這是正常行為。
